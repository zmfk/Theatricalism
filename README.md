# 剧场主义 · 全档案馆

《剧场主义》的静态档案站：一套自创的实践哲学，从 0.3 到 6.0 的全部推演、132 条概念、20 份希腊字母记录（α 到 χ）与 159 章对话录，拆成可单独打开、单独链接的多文件站。

打开 `index.html` 即可阅读，不需要服务器，也不需要构建。

## 怎么读

先读 `axioms/` 的六块承重墙，再翻 `concepts/` 里的「地板 / 存在₁／存在₂ / 裁决 / 接口」。想追版本演变去 `versions/`，想看现场怎么推出来进 `dialogue/`。理论停在 6.0；7.x 是档案版本——拆分页面、去重、加索引与矩阵，不新增理论章节。

## 内容边界

这不是同行评议出版物，也不是要成立的学派宣言。对话录是施工现场，问题被反复拆开又装回去；引用时请以理论正文与原始记录为准，不要把现场推理当成理论结论。涉及他人与个人经历的具体细节已泛化或删除，因此章节编号保留原值、并不连续。

引用请标注「剧场主义 6.0 + 档案 7.4」，并自行核对该条在概念词典里的原文段落。

## 技术

纯 HTML / CSS / JavaScript，无框架、无构建步骤、无外部 CDN、无追踪脚本；所有页面用相对链接，可直接放在任意静态托管的子路径下。`.nojekyll` 用于让 GitHub Pages 跳过 Jekyll 处理。

顶栏右侧有「A- / A+」字号档位（小 / 标准 / 大，存在 `localStorage.th-fs`）与主题切换（`th-theme`）；档位是 `html[data-fs]` 上的 CSS 变量 `--fs`，`--navh` 由 `site.js` 按顶栏实测高度写回，保证锚点滚动不被吸顶栏挡住。

> 注意：`scripts/build_site.mjs --rebuild` 是整站重建，它自带一份 `assets/style.css` / `site.js` 与页面模板，**不含**上述字号档位（顶栏按钮、CSS 档位、`--navh` 同步）。重建后需重新补上，或改用 `node scripts/nav74_rebuild.mjs`（已含 A-/A+ 按钮）。

> 对话录分册：源流卷 20 册（α—χ，每份工作日志一册）+ 正篇 7 册（按理论版本分节）。目录页与首页「07 对话录」板块是 4 列希腊方块网格（源流 20 块 = 5 行）。改完章块或分组后跑 `node scripts/build_dialogue_books.mjs`（幂等；分组表在脚本顶部的 `SRC` / `MAIN`），它会重建 27 册、重写目录与首页方块、并把全站 `dialogue/.../#dlg-N` 链接改写到新册；`--dry` 只打印分册计划。`build_site.mjs --rebuild` 会按旧分页覆盖，重建后需重跑它。

## 发布

本仓库是站点的**发布快照**，内容即上面这些 `.html`。生成脚本、拆分日志与工作区原文不随本仓库发布，所以上文提到的 `scripts/*.mjs` 在这里找不到。

推送到 `main` 后，`.github/workflows/pages.yml` 会把它发布到 <https://zmfk.github.io/Theatricalism/>。`upload-pages-artifact` 自动排除 `.git` 与 `.github`，站点产物里不会带上仓库元数据。
